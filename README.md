- Open the **[live demo](https://quantum-chemistry-cd6e.seedlabs.tech)** and click through it like an end user — the screens, flows and interactions are the point.
- It is AI-generated and front-end only: every value is illustrative, nothing is persisted, and no real backend is connected. Feel the product; don't run it in production.
